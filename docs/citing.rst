Citing
======

If you use **dmokit** in your research, please cite both the accompanying paper
and the specific version of the software you used.

Paper
-----

The methodology paper is currently **submitted**. The citation and DOI will be
added here once it is published.

.. code-block:: bibtex

   @article{boschi_dmokit,
     title   = {dmokit: An Open-Source Python Framework for Standardized
                Extraction of Real-World Digital Mobility Outcomes from Wearable
                Inertial Foot Sensors},
     author  = {Boschi, Francesca and Terranova, Francesca and Sapienza, Stefano
                and Ragon, Gaetan and Klucken, Jochen},
     note    = {Manuscript submitted},
     year    = {2026}
   }

Software
--------

Please also cite the version of the software you used. A citable, versioned
release with a DOI (via Zenodo) is planned; until then, cite the repository and
the commit/version.

.. code-block:: bibtex

   @software{dmokit_software,
     title     = {dmokit: standardized extraction of real-world Digital Mobility
                  Outcomes from foot-worn IMUs},
     author    = {Boschi, Francesca and Terranova, Francesca and Sapienza, Stefano
                  and Ragon, Gaetan and Klucken, Jochen},
     url       = {https://github.com/fraboschi98/DMOs_pipeline},
     version   = {x.y.z},
     year      = {2026}
   }
